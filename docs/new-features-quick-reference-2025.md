# New Features Quick Reference - 2025

## 🆕 What's New This Year

### 1. Combined Quarter Report
**What**: Q1+Q2 combined performance analysis  
**Where**: Reports Hub → Combined Quarter Report  
**When to use**: End-of-semester reports, parent meetings  
**Key features**: Completion %, average scores, final totals, sorted by performance

### 2. Multi-Quarter Access Management  
**What**: Allow students to access past quarter assessments  
**Where**: Multi-Quarter Access (Student Management section)  
**When to use**: Students who missed Q1 work, catch-up periods  
**Key features**: Class-specific access, deadline management, Q1+Q2 badges

### 3. Enhanced Assessment Due Date Manager
**What**: Manage due dates for all quarters (Q1+Q2)  
**Where**: Assessment Due Date Manager  
**When to use**: Setting deadlines for Q1 assessments, extending deadlines  
**Key features**: Shows Q1+Q2 assessments, batch operations, status filtering

### 4. Centralized Reports Hub
**What**: Single access point for all reporting tools  
**Where**: Reports Hub (main navigation)  
**When to use**: Quick access to any report  
**Key features**: Organized categories, new features highlighted

## 🎯 Quick Start Guide

### For End-of-Semester Reports
1. Go to **Reports Hub**
2. Click **Combined Quarter Report**
3. Select: English → Project Explore 2 → Your Class
4. View students sorted by performance
5. Use for parent meetings and semester summaries

### For Students Who Missed Q1 Work
1. Go to **Multi-Quarter Access** (Student Management)
2. Select your subject and class
3. Enable multi-quarter access
4. Set reasonable catch-up deadline (1-2 weeks)
5. Students can now access Q1+Q2 assessments

### For Managing Q1 Assessment Deadlines
1. Go to **Assessment Due Date Manager**
2. Set filters: Status = "No Due Date", Quarter = "Q1", Subject = "Project Explore 2"
3. Click **Refresh**
4. Assign due dates to Q1 assessments
5. Students will see deadlines in their portal

## 🔧 Common Tasks

### Setting Up Catch-Up Work
1. **Enable access**: Multi-Quarter Access → Enable for class
2. **Set deadline**: Add reasonable catch-up deadline
3. **Monitor progress**: Check student completion rates
4. **Disable when done**: Turn off access after catch-up period

### Generating Semester Reports
1. **Combined data**: Use Combined Quarter Report for Q1+Q2 overview
2. **Individual details**: Use Individual Student Report for specific students
3. **Export options**: CSV/Markdown export available
4. **Parent communication**: Use for parent meeting preparation

### Managing Assessment Deadlines
1. **Find Q1 assessments**: Filter by "No Due Date" status
2. **Set deadlines**: Assign reasonable due dates
3. **Extend if needed**: Use batch extension for class-wide changes
4. **Communicate**: Inform students of deadline changes
