## Student Progress Tracking

**🆕 NEW: Skills-Based Progress Tracking System**

Our platform now features advanced skills-based progress tracking that monitors student development across specific language skills: Reading, Grammar, Speaking, Listening, Vocabulary, and Writing.

### Class Progress View

**Location**: Teacher Portal → Student Progress

#### Features
- View all students in a selected class
- Filter by quarter (Q1, Q2, Q3, Q4)
- **NEW**: Skills-based progress breakdowns for each student
- Track completion rates and scores by skill category
- Export class data to CSV with skill analysis
- Individual student report access with skill details

#### Skills Tracked
- **Reading**: Comprehension, analysis, and interpretation skills
- **Grammar**: Sentence structure, tenses, and language rules
- **Speaking**: Oral communication and pronunciation
- **Listening**: Audio comprehension and understanding
- **Vocabulary**: Word knowledge and usage
- **Writing**: Composition, structure, and written expression

#### How to Use
1. Select your class from the dropdown
2. Choose quarter filter (optional)
3. View student performance data organized by skills
4. Click individual report buttons for detailed skill analysis
5. Use "Download CSV" for class data export with skill breakdowns

### Individual Student Reports

**Location**: Teacher Portal → Individual Student Report

#### Features
- Detailed performance analysis for specific students
- **NEW**: Skills-based progress breakdown (e.g., Reading: 85%, Speaking: 60%)
- Quarter-specific skill development tracking
- Subject-wise performance metrics organized by skills
- Assessment submission history categorized by skill type
- Progress tracking over time with skill trend analysis
- Comprehensive skill-based statistics

#### How to Use
1. Select a student from the dropdown
2. Choose quarter filter (Q1, Q2, Q3, Q4, or All Quarters)
3. Click "Generate Report"
4. View comprehensive student data
5. Use data for parent meetings and interventions

## Database Export System

### Export Modes

#### 1. All Quarters (Comprehensive)
- **Purpose**: Complete data export with quarter separation
- **Includes**: All data tables + separate Q1, Q2, Q3, Q4 sheets
- **Best for**: Complete system analysis and reporting

#### 2. Specific Quarter
- **Purpose**: Data from selected quarter only
- **Includes**: Filtered data for Q1, Q2, Q3, or Q4
- **Best for**: Quarter-specific analysis

#### 3. Export All
- **Purpose**: All available data tables
- **Includes**: Complete system data
- **Best for**: Comprehensive data analysis

#### 4. Parent Reports
- **Purpose**: Single-click export for parent reports
- **Includes**: Student Performance Dashboard only
- **Best for**: End-of-term parent communication

### Available Data Tables

#### Core Data
- **Users**: Student and teacher information with relationships
- **Subjects**: Course structure with statistics
- **Course Structure**: Units, parts, sections hierarchy
- **Resources**: Learning materials with usage data
- **Assessments**: Quizzes and assignments with metadata
- **Submissions**: Student responses and scores
- **Progress**: Student progress tracking
- **Student Courses**: Enrollment data
- **Teacher Assignments**: Teacher-subject assignments

#### System Data
- **Weekly Schedules**: Lesson plans and objectives
- **User Sessions**: Login and activity tracking
- **Resource Usage**: Usage analytics
- **Media Files**: Uploaded content
- **Transfer Logs**: Teacher transfer history
- **Configuration**: System settings

#### Quarter-Specific Data
- **Resources_Q1, Q2, Q3, Q4**: Quarter-specific resources
- **Assessments_Q1, Q2, Q3, Q4**: Quarter-specific assessments
- **Submissions_Q1, Q2, Q3, Q4**: Quarter-specific submissions

- Quarter-by-quarter performance breakdown

## Troubleshooting

### Common Issues

#### Export Fails
- **Problem**: Export doesn't complete
- **Solution**: Check internet connection, try smaller data sets
- **Prevention**: Use stable connection, export during off-peak hours

#### Missing Data
- **Problem**: Incomplete data in export
- **Solution**: Verify quarter settings and data availability
- **Prevention**: Check data completeness before generating reports

#### Slow Performance
- **Problem**: Export takes too long
- **Solution**: Use specific quarter filters, close other applications
- **Prevention**: Export during off-peak hours, use quarter-specific exports

#### File Too Large
- **Problem**: Excel file too large to open
- **Solution**: Use quarter-specific exports, filter data
- **Prevention**: Export smaller data sets, use CSV format
