# Assessment Due Date Manager Guide

## Overview

The Assessment Due Date Manager allows teachers to quickly adjust assessment due dates without full editing. It provides both batch operations and individual assessment management capabilities.

**🆕 UPDATED**: The Assessment Due Date Manager now shows assessments from both Q1 and Q2, allowing teachers to manage due dates for past quarter assessments.

## Location

**Access**: Teacher Portal → Assessment Due Date Manager  
**URL**: `/teacher/assessment-manager.html`

## Key Features

### Batch Actions

**Extend All Due Dates**
- Select number of days to extend (1 day, 3 days, 1 week, 2 weeks)
- Apply to all assessments matching current filters
- Useful for class-wide deadline adjustments

**Filters for Batch Operations**
- **Quarter Filter**: Q1, Q2, Q3, Q4, or All Quarters
- **Subject Filter**: Select specific subjects (e.g., Project Explore 2)

### Individual Assessment Management

**Search and Filter**
- Search by assessment title or subject name
- Filter by status: All, Overdue, Due Soon, Upcoming, No Due Date
- Filter by quarter and subject

**Due Date Management**
- View current due dates for all assessments
- Edit individual assessment due dates
- See status indicators (overdue, due soon, upcoming)
- Save changes individually or in batches

## Understanding Assessment Status

### Status Categories

**Overdue**
- Assessments with due dates that have passed
- Red border indicator
- Priority for deadline management

**Due Soon**
- Assessments due within 3 days
- Yellow border indicator
- May need deadline extensions

**Upcoming**
- Assessments with future due dates (more than 3 days)
- Green border indicator
- Normal status

**No Due Date**
- Assessments without due dates set
- Most Q1 assessments fall into this category
- Can be assigned due dates as needed

## Common Use Cases

### Managing Q1 Assessments

**Problem**: Q1 assessments don't have due dates set, so students can't see deadlines.

**Solution**:
1. Set **Status Filter** to "No Due Date"
2. Set **Quarter Filter** to "Q1"
3. Set **Subject Filter** to your subject (e.g., "Project Explore 2")
4. Click **Refresh**
5. Assign due dates to assessments as needed

### Extending Deadlines

**Scenario**: Need to extend all Q2 assessment deadlines by 1 week.

**Solution**:
1. Set **Quarter Filter** to "Q2"
2. Set **Subject Filter** to your subject
3. Select "1 week" from "Extend all due dates by" dropdown
4. Click **Apply Extension**
5. All matching assessments will have their due dates extended

### Finding Overdue Assessments

**Scenario**: Need to see which assessments are past due.

**Solution**:
1. Set **Status Filter** to "Overdue"
2. Set appropriate **Quarter** and **Subject** filters
3. Click **Refresh**
4. Review overdue assessments and extend deadlines if needed

## Best Practices

### Setting Due Dates for Q1 Assessments

1. **Check Multi-Quarter Access**: Ensure students have access to Q1 assessments if needed
2. **Set Reasonable Deadlines**: Consider giving students 1-2 weeks for catch-up work
3. **Communicate Changes**: Inform students of new deadlines
4. **Monitor Progress**: Check student completion rates after deadline extensions

### Batch Operations

1. **Test with Small Groups**: Try batch operations with a few assessments first
2. **Verify Results**: Check that due dates were extended correctly
3. **Document Changes**: Keep track of deadline extensions for reference

### Individual Management

1. **Use Filters Effectively**: Combine filters to find specific assessments quickly
2. **Save Changes**: Remember to save individual changes after editing
3. **Review Status**: Check assessment status after making changes

## Troubleshooting

### Q1 Assessments Not Showing

**Problem**: Q1 assessments don't appear when filtering by "Overdue"

**Solution**: Most Q1 assessments have no due dates set. Use "No Due Date" status filter instead.

### Assessments Not Loading

**Problem**: Assessment list shows "Loading..." indefinitely

**Solution**: 
1. Check internet connection
2. Refresh the page
3. Verify you have proper teacher permissions

### Batch Extension Not Working

**Problem**: "Apply Extension" button doesn't extend dates

**Solution**:
1. Ensure assessments match current filters
2. Check that you have write permissions
3. Try extending individual assessments first

## Integration with Other Features

### Multi-Quarter Access

- When students have multi-quarter access enabled, they can see Q1+Q2 assessments
- Due dates set here will appear in the student portal
- Students see deadline warnings for approaching due dates

### Reporting

- Due date information is included in progress reports
- Overdue assessments affect student completion rates
- Deadline extensions are tracked in system logs

## Security and Permissions

- Only teachers and admins can access this feature
- Changes are logged for audit purposes
- Due date changes are immediately reflected in student portal
- Batch operations require confirmation to prevent accidental changes
